# Support (removed)

> **This endpoint has been removed.** `/api/v1/support` is no longer mounted in
> `app.js`. It has been replaced by the chat-based ticketing system at
> `/api/v1/tickets` (see `routes/client/ticket.routes.js` and
> `routes/admin/ticketManagement.routes.js`). The old `support_tickets` table
> and its model/controller/routes files are left in place, unused, as
> historical data — not deleted.
